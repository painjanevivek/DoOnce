# Satoshi Typeface

DoOnce uses Satoshi through Fontshare's official stylesheet API. The application does not copy, modify, or redistribute the proprietary font files.

- Typeface: [Satoshi](https://www.fontshare.com/fonts/satoshi)
- License: [ITF Free Font License 1.0](https://www.fontshare.com/licenses/itf-ffl)
- Stylesheet API: `https://api.fontshare.com/v2/css?f[]=satoshi@300,400,500,700,900&display=swap`
- Retrieved: 2026-08-10
- Runtime font host: `https://cdn.fontshare.com`
- Fallback: `"Segoe UI", Arial, sans-serif`

The external stylesheet and font origins are narrowly allowlisted in the production Content Security Policy. If Fontshare is unavailable, the system fallback preserves content and controls without layout-dependent functionality.
